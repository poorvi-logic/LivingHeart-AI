LivingHeart AI

3D Cardiac Visualization and Surgical Procedure Simulation

Overview

LivingHeart AI is a 3D cardiac visualization and surgical simulation project developed using Blender and Unity. It focuses on demonstrating three important cardiac procedures through 3D visualization, supported by animated heart behaviour, biofeedback functionality and an illustrative Reinforcement Learning (RL) concept.

Key Features

1. Cardiac Surgical Procedure Simulations

The project demonstrates three cardiac procedures:

* Arrhythmia Treatment: 3D visualization of an arrhythmia-related treatment procedure.
* Heart Valve Replacement: Simulation and visualization of a heart valve replacement procedure.
* Pacemaker Surgery: 3D visualization of pacemaker implantation.

These simulations aim to make cardiac procedures easier to understand through visual demonstrations.

2. 3D Heart Modelling and Visualization
* Created the 3D heart model using Blender.
* Applied textures, colours, materials and visual detailing to enhance its appearance.
* Integrated the 3D heart model into Unity.
* Developed animated heart behaviour and visual representations of cardiac structures.
3. Biofeedback Functionality
* Implemented biofeedback-based heart behaviour.
* Demonstrates changes in heart visualization based on biofeedback input.
4. Reinforcement Learning Illustration
* Includes an illustrative representation of Reinforcement Learning concepts.
* Demonstrates the concept of adaptive behaviour.
* This is an illustration, not a trained or deployed RL model.

Technologies Used

* Blender: 3D modelling, texturing, materials and visual detailing.
* Unity: 3D visualization, animation and surgical simulation.
* C#: Unity scripting and functionality.
